01מגדירים מוצר ראשון ומדדי הצלחה
MVP · תכנון · 30–45 דקות⌄

התוצר הראשון: סרטון אנכי בן 30–60 שניות, בעברית או באנגלית, שבו הכפיל שלך מסביר מושג טכנולוגי. בלי בניית SaaS מוקדמת.

החלטות

תוצר: קובץ brief.md עם topic, audience, language, duration, tone וקריטריוני QA.
02מקליטים חומר מקור ובונים Digital Twin
MVP · HeyGen · תלוי אימות ואישור ספק⌄

הקלט סרטון חד וברור מול המצלמה. דיבור רגיל, תאורה אחידה, רקע נקי, בלי רעש ובלי עריכות. פעל לפי הוראות הצילום וההסכמה העדכניות של הספק.

  1. פתח חשבון ב-HeyGen.
  2. בחר יצירת Digital Twin / Custom Avatar (שמות המסכים עשויים להשתנות).
  3. העלה סרטון מקור ובצע אימות זהות והסכמה.
  4. המתן לאישור האווטאר והכן בדיקת דיבור ראשונה.
השתמש רק בפנים שלך או בדמות שהעניקה הסכמה מפורשת. בדוק אם תוכנית HeyGen שלך מאפשרת שימוש ב-API עבור סוג האווטאר שבחרת.
03משכפלים קול ומוודאים עברית טבעית
MVP · ElevenLabs · ניסויי איכות⌄

הקלט דיבור נקי ושמור דגימות של עברית ואנגלית. איכות הדגימה והמודל משפיעים על התוצאה, ואין הבטחה לשימור מבטא מושלם.

  1. היכנס ל-ElevenLabs ופתח את מסך הקולות.
  2. בדוק זמינות Voice Cloning במסלול שלך ואמת בעלות/הסכמה.
  3. העלה דגימת קול נקייה לפי דרישות הכלי.
  4. בדוק 4 משפטים: עברית, אנגלית, מושגים טכניים ושמות פרטיים.
אל תשלח API keys לדפדפן או ל-GitHub. הקול והאווטאר הם שני נכסים שונים, ויש לבדוק כיצד מסנכרנים ביניהם.

06בונים Research + Script Agents
AUTOMATION · LLM · Prompt Engineering⌄

התחל בשני תהליכים פשוטים עם JSON מובנה. מחקר צריך להחזיר מקורות וקישורים, ולא להמציא אסמכתאות. תסריט צריך לציין מקומות לא ודאיים ולבקש אישור.

Prompt ל-Script Agent
You are a technical video scriptwriter for an experienced software engineering leader.
Input: {topic, audience, language, durationSeconds, researchSources, voiceStyle}.
Output valid JSON:
{
  "hook": "...",
  "scenes": [{"id": 1, "narration": "...", "visual": "...", "durationSeconds": 8}],
  "claimsToVerify": [],
  "sources": [],
  "cta": "..."
}
Rules:
- Avoid invented facts, exaggerated claims and filler.
- Match the requested language and estimated reading time.
- Explain one key concept per scene.
- Flag any uncited claim for human review.
- Do not imitate a real person's views unless backed by supplied source material.
07מחברים API ליצירת קול ואווטאר
AUTOMATION · API adapters · Webhooks⌄

צור adapters שמסתירים הבדלים בין ספקים. בדוק בתיעוד העדכני אילו תכונות נתמכות בחשבונך, במיוחד Custom Avatar, Voice ID ואפשרות הגשת audio חיצוני.

חוזה TypeScript מומלץ
interface VoiceProvider {
  synthesize(input: { text: string; voiceId: string; language: string }): Promise<{ audioUrl: string }>;
}
interface AvatarProvider {
  createVideo(input: { avatarId: string; script?: string; audioUrl?: string }): Promise<{ jobId: string }>;
  getStatus(jobId: string): Promise<{ status: 'queued'|'running'|'done'|'failed'; videoUrl?: string }>;
}
interface VideoJob {
  id: string;
  stage: 'draft'|'awaiting_approval'|'rendering'|'review'|'done'|'failed';
  updatedAt: string;
}

09Orchestrator, תורים וחיבור ל-Telegram
AUTOMATION · NanoClaw / Bot · Workflow⌄

השאר ל-NanoClaw את התקשורת מולך. שירות backend יבצע את העבודה באמצעות queue, יאחסן artifacts ויחזיר סטטוס. אל תריץ עבודות רנדר כבדות בתהליך הראשי של הבוט.

הודעות לדוגמה
/video topic="AI Agents vs Chatbots" lang=he duration=60
/status job_123
/approve job_123
/reject job_123 reason="shorten the intro"
הגבל הרשאות: whitelist של משתמשי Telegram, אימות webhook, הגבלת עלויות, ואישור מפורש לפני הפצה חיצונית.
10הופכים את הפרויקט למוצר רב-משתמשים
SAAS · Backend · Multi-tenant⌄

כאן עוברים מ-"סוכן בשבילי" למוצר ללקוחות. אפשר להשתמש ב-Java/Spring Boot לאורקסטרציה העסקית ו-Node workers עבור Remotion.

רכיבי מוצר

  • Auth + Organizations + Roles + tenant isolation.
  • Project, Script, AvatarProfile, VoiceProfile, Job, Artifact, Approval.
  • PostgreSQL לנתונים ו-Object Storage לקבצים.
  • Queue לעיבודים, Worker נפרד לרנדר, Observability.
  • Billing, quotas, usage ledger והגבלת עלויות לכל לקוח.

06 / QUESTIONS

לפני שמתחילים

אפשר לבנות הכול בחינם?

אפשר לבנות שלד, prompts ותבנית עריכה בעלות נמוכה, אבל יצירת אווטאר, קול ושימוש ב-API עשויים לדרוש מנויים או תשלום לפי שימוש. אין כאן הבטחה למסלול חינמי מלא.

חייבים גם HeyGen וגם ElevenLabs?

לא בהכרח. בשלב ה-MVP אפשר להתחיל עם הקול המובנה של HeyGen. ElevenLabs שימושי כאשר צריך יותר שליטה בקול, בתנאי שקיימת אינטגרציה מתאימה לספק האווטאר.

למה לא לבנות SaaS מהיום הראשון?

כי הסיכון הראשון הוא איכות הסרטון ועלותו. כדאי לוודא שהפלט מרשים ושאנשים ירצו בו לפני השקעה בבילינג, הרשאות וממשק ללקוחות.

איך מגינים על הכפילים של לקוחות?

אימות והסכמה ברורים, הרשאות מוגבלות, הצפנת נתונים, הגבלת גישה למפתחות, מחיקה לבקשת לקוח, audit logs ואישור לפני פרסום. אל תאפשר יצירת כפיל של צד שלישי ללא הרשאה.

איך שומרים את ההתקדמות באתר?

תיבות הסימון נשמרות רק ב-localStorage של הדפדפן הנוכחי. הן לא מסתנכרנות בין מכשירים ולא מועלות לשרת.
